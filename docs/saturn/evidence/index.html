Preserved failure: press detection is proven, but this run still shows DOWN 8000 after the emulator override ends. Deterministic remote release remains the next debugger fix.

13 · CPU performance pass · manually accepted

Stop transforming shared data repeatedly

Surface depths are cached, the previous painter order is retained, and each of 440 face vertices is transformed/projected once per frame. Manual SDL testing confirmed a major responsiveness improvement; retail-hardware timing remains unclaimed.

14 · True-quad render IR

156 real quads, source triangles retained

A deterministic host compiler validates material, winding, normal alignment, and convexity across 15 camera samples. Face commands fall from 877 to 721; total draw commands fall from 1,213 to 1,057 while unsafe pairs remain explicit triangle fallbacks.

15 · Exact host optimizer

Maximum pairing, now proven

Hash-pinned NetworkX 3.6.1 uses exact integer blossom matching. It proves 156 is the maximum under current safety gates and improves global pair quality with an identical silhouette mask.

16 · Reusable mesh IR v1

Source identity + real Goddard weights

The generic compiler preserves 877 source triangle IDs, 41 ordered joints, and all 506 unnormalized Q15 weight records. Its BIOS-backed framebuffer is bit-identical to Stage 15, proving the new data boundary introduces no neutral-render regression.

17 · Boot timing diagnostic

Capture too early

The initial 2,100-frame USA-BIOS route stopped at the Sega logo. Extending the same route to 3,300 frames reached the demo; this is preserved as automation evidence, not a renderer frame.

18 · Rejected animated quad

Static merge, moving vertex

At a deterministic later eyelid phase, a quad accepted in the neutral pose broke the face. A repeat produced the same framebuffer hash: this is a real animation-safety failure, not a screenshot race.

19 · Animation-safe fallback

42 weighted vertices stay triangular

108 eyelid-region source triangles now bypass quad merging; 130 static safe quads remain. The same later phase returns a complete face while the full Goddard pose evaluator remains future work.

20 · Preserved M1 compositor failure

NBG1 is active, but its bitmap is black

The priority test proves NBG1 overlays VDP1, but its direct-fill bitmap remains black in Ymir. The face-visible build is retained; a minimal isolated Yaul bitmap probe is the next integration gate.

21 · M1 VDP2 backdrop accepted

VDP2 title field is composited behind Mario

A standalone NBG1 probe found the missing VDP2 VRAM cycle pattern. Its A0/A1 fetch allocation now renders the original RGB555 staging field behind VDP1 Mario. PRESS START/NBG3 remains the next title-layer gate.

22 · M1 title prompt

PRESS START is now in the title bitmap

The player-facing prompt uses the proven NBG1 field rather than the still-instrumentation-only NBG3 debug font. It intentionally sits behind VDP1 Mario; a Start edge changes the bitmap to STARTED.

23 · M1 original glyphs

The temporary block font has been replaced by six locally converted US SM64 HUD glyphs. Derived Nintendo pixels and the ROM manifest remain under untracked build output; the converter is tracked.

24 · Corrected source glyph and eyelid ordering

The original glyphs are now decoded after MIO0 Segment 2 decompression. Strongly weighted upper-face triangles are drawn ahead of the separate eye objects, exposing the eyelid contour. Full joint-matrix motion remains next.
