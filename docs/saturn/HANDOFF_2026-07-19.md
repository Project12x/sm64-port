### 2026-07-19 source-data closure implementation

The narrowed direct-Bob source build reaches final link but retains 1.67 MiB
of real source `.rodata`; Yaul's HWRAM first-read image overflows by 1,748,848
bytes. This is an expected residency boundary, not an excuse to reintroduce a
viewer. Read [`e2-bob-source-data-closure-2026-07-19.md`](evidence/e2-bob-source-data-closure-2026-07-19.md)
before modifying the target.

The direct-source compatibility bank is now implemented: `SOURCE.DAT` is the
final `.cart_rodata` image linked at `0x22400000`, included in the E2 ISO, and
loaded before `thread5_game_loop()` through `CD -> 16 KiB WRAM staging -> 4 MiB
DRAM cart`. `source_cart.c` requires Yaul cart ID `0x5C`, checks the precise
linked byte count, and exports `g_sm64_saturn_source_cart_probe` for remote
diagnosis. The full package/build evidence is
[`e2-sourceboot-cart-bank-2026-07-19.md`](evidence/e2-sourceboot-cart-bank-2026-07-19.md).

The headless no-cart negative control now reaches the source loader after the
documented pause/resume handoff: it reports `SCAR`, `FAILED`, and
`MISSING_4MIB`, with the expected 1,694,864-byte source-bank size. This proves
the source loader executes before source data dereference; it is not a
cart-enabled result. The next task is a real 32 Mbit-cart Ymir SDL boot and
probe read. Do not use the existing headless debugger as a cart verdict: it
